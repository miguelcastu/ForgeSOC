DESIGN PRINCIPLES

Why it stays understandable

Explicit boundaries

Raw schemas, domain models and database rows have separate responsibilities.

Replay-safe

Stable identities make ingestion and detection idempotent.

Explainable by default

Alerts retain every event used as evidence, in order.

Measured evolution

Each sprint adds infrastructure only when a limitation justifies it.

QUICK REFERENCE

Concepts worth explaining

Canonical event

A provider-neutral security fact consumed by every detector.

Adapter

A source-specific translator behind one normalization contract.

Sliding window

Only failures inside the active 60-second interval are counted.

Idempotency

Replaying the same input changes no stored result.

Evidence link

An ordered relationship from an alert to the events that justify it.

ADR

A short record explaining why an architectural decision was taken.
